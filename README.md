## Hi, I'm Leandro Ortegón

Systems Engineering student at **Universidad del Quindío** (Colombia), building a foundation in software development and software engineering.

Most of my work comes from university courses and personal practice: object-oriented programming in **Java**, functional and concurrent programming in **Elixir**, and data analysis and automation with **Python**. I use GitHub to keep a record of that learning path, from first exercises to larger team projects.

- **Languages:** Java · Python · Elixir · SQL

- **Python:** pandas, matplotlib, seaborn, Jupyter, SQLite, TensorFlow/Keras, Telegram bots
